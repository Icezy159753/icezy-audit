# Security policy

Do not post API keys, passwords, personal data, private project evidence or exploit-bearing user files in public issues.

For a suspected installer vulnerability, use GitHub's private vulnerability-reporting feature IF enabled for this repository, or contact the maintainer privately using a channel visible on their GitHub profile. Do not assume private reporting is enabled until the repository Security tab confirms it. Generic questions and non-sensitive reproducible bugs may use Issues.

Include affected release, OS/Python version, command with secrets removed, the managed path category, expected/observed behavior and a minimal synthetic fixture. Do not run a proof against another user's home, shared services or production systems.

Scope: safe local file installation/removal, packaging integrity and prompt/control descriptions. Guidance does not guarantee agent obedience, application security, provider provenance or legal compliance. The supported release is the latest published stable release; no contractual response-time SLA is claimed.
