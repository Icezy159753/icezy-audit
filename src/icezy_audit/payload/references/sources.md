# Primary references

Reference baseline checked 2026-11-22. Recheck current editions and exact stack documentation at each kickoff. These are different kinds of references, not interchangeable certifications.

- OWASP ASVS 5.0.0, published 2025-05-30; official project identifies it as latest stable when checked: https://owasp.org/www-project-application-security-verification-standard/
- ASVS release requirements and version-pinned mappings: https://github.com/OWASP/ASVS/tree/v5.0.0 ; never invent requirement IDs from internal baseline IDs.
- OWASP Top 10:2025, awareness document: https://owasp.org/Top10/2025/
- OWASP API Security Top 10:2023: https://api-security.owasp.org/editions/2023/en/0x11-t10/
- OWASP MASVS and MASTG, verify mobile controls/test mappings: https://mas.owasp.org/MASVS/ and https://mas.owasp.org/MASTG/
- NIST SP 800-63B-4, password length, blocklists, authenticator management and phishing resistance: https://pages.nist.gov/800-63-4/sp800-63b.html
- OWASP Cheat Sheet Series; current focused implementation guidance: https://cheatsheetseries.owasp.org/
- NIST SSDF development-process reference: https://csrc.nist.gov/projects/ssdf
- Thai PDPC official guidance/legal texts and current notices: https://www.pdpc.or.th/ ; confirm applicable provisions with qualified review, not a generic consent checklist.
- EU GDPR official text: https://eur-lex.europa.eu/eli/reg/2016/679/oj
- PCI SSC official standards: https://www.pcisecuritystandards.org/document_library/ ; determine actual merchant/system scope.
- Hermes creating skills and progressive disclosure: https://hermes-agent.nousresearch.com/docs/developer-guide/creating-skills and https://hermes-agent.nousresearch.com/docs/user-guide/features/skills

Important qualifications: ASVS-inspired baseline is not full-level conformity; Top 10 coverage is not exhaustive testing; NIST requirements depend on claimed assurance/profile; PDPA/GDPR/PCI applicability cannot be decided solely from a framework name or presence of a payment button.
